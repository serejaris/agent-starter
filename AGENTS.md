## Трекинг задач (todo.md)

- В todo.md попадает задача, у которой есть критерий готовности (см. CONTEXT.md).
  Если критерий сформулировать нечем - это мелкая правка, она не трекается.
- Перед началом работы проверяй todo.md: есть ли уже такая задача. Если нет - добавь со статусом todo или сразу in-progress.
- Формулируй задачу как проверяемый сценарий: что меняется, в каких файлах, каков критерий готовности.
- По ходу работы обновляй статус: todo → in-progress → done. Завершённые задачи не удаляются, остаются в файле.

## Журнал прогресса (progress.md)

- В начале сессии читай progress.md, чтобы понять текущей задачи.
- в этом файле должно быть описание только этой задачи
