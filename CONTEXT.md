# Agent Starter

Шаблон папки-проекта для работы агентов: правила, задачи, журнал прогресса.

## Language

**Критерий готовности**:
Проверяемое условие, по которому задача считается сделанной. Задача без критерия готовности в todo.md не попадает.
_Avoid_: definition of done, acceptance criteria

**Мелкая правка**:
Изменение, для которого нечем сформулировать критерий готовности; в todo.md не трекается.
_Avoid_: содержательная задача (как противопоставление)

**Участник**:
Агент проекта с ролью и зоной ответственности. Люди участниками не считаются.
_Avoid_: сотрудник, член команды

**Журнал прогресса**:
Файл progress.md с итогами сессий: что сделано и как проверено.
_Avoid_: контекст сессии, лог
