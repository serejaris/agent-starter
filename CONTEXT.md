# Agent Starter

Шаблон папки-проекта для работы агентов: правила, задачи, карточки прогресса.

## Language

**Критерий готовности**:
Проверяемое условие, по которому задача считается сделанной. Задача без критерия готовности в трекинг не попадает.
_Avoid_: definition of done, acceptance criteria

**Мелкая правка**:
Изменение, для которого нечем сформулировать критерий готовности; не трекается.
_Avoid_: содержательная задача (как противопоставление)

**Участник**:
Агент проекта с ролью и зоной ответственности. Люди участниками не считаются.
_Avoid_: сотрудник, член команды

**Карточка задачи**:
Файл `tasks/WNN/<слаг>.md` с описанием одной задачи: сценарий, критерий готовности, ссылки, прогресс.
_Avoid_: тикет, issue, журнал прогресса

**Индекс задач**:
Файл tasks.md: строка на задачу со статусом и ссылкой на карточку.
_Avoid_: список задач, доска, todo
