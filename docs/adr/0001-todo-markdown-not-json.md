# todo.md в Markdown, а не в JSON

Антропик для длительных автономных прогонов рекомендует вести список задач в JSON: модель реже неуместно переписывает JSON-файлы, чем Markdown ([Effective harnesses for long-running agents](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents)). Мы оставили todo.md в Markdown: файл правят и человек, и агент, читаемость важнее, а полностью автономных многосессионных прогонов в шаблоне нет. Появятся такие прогоны - решение пересмотреть.
