# Трекинг задач (todo.md)

Источник правил - AGENTS.md. Этот скилл - их механика применительно к todo.md.

## Настройка (если чего-то не хватает)

- Если в AGENTS.md нет раздела "Трекинг задач (todo.md)" - добавь его дословно:

  ```
  ## Трекинг задач (todo.md)

  - В todo.md попадает задача, у которой есть критерий готовности (см. CONTEXT.md).
    Если критерий сформулировать нечем - это мелкая правка, она не трекается.
  - Перед началом работы проверяй todo.md: есть ли уже такая задача. Если нет - добавь со статусом todo или сразу in-progress.
  - Формулируй задачу как проверяемый сценарий: что меняется, в каких файлах, каков критерий готовности.
  - По ходу работы обновляй статус: todo → in-progress → done. Завершённые задачи не удаляются, остаются в файле.
  ```

- Если файла `todo.md` в корне проекта нет - создай его:

  ```
  # Todo

  ## Задачи

  ```

## Перед началом задачи

1. Проверь, есть ли у задачи критерий готовности. Если критерий сформулировать нечем - это мелкая правка, трекинг не нужен.
2. Открой `todo.md` и проверь, нет ли уже такой задачи.
3. Если задачи нет - добавь её: формулировка как проверяемый сценарий (что меняется, в каких файлах) плюс строка с критерием готовности, статус `todo` или сразу `in-progress`.
4. Если задача есть - переведи её в `in-progress`.

## По ходу работы

Обновляй статус задачи по мере продвижения: `todo` → `in-progress` → `done`.

## По завершении работы

Сверь результат с критерием готовности и пометь задачу как `done`. Завершённые задачи не удаляются - остаются в файле.
