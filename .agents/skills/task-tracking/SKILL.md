# Трекинг задач (tasks/)

Источник правил - AGENTS.md. Этот скилл - их механика применительно к tasks.md и карточкам.

## Настройка (если чего-то не хватает)

- Если в AGENTS.md нет раздела "Трекинг задач (tasks/)" - добавь его дословно:

  ```
  ## Трекинг задач (tasks/)

  - Задача, у которой есть критерий готовности (см. CONTEXT.md), живёт в отдельной карточке: `tasks/WNN/<слаг>.md`, где WNN - номер недели ISO.
    Если критерий сформулировать нечем - это мелкая правка, она не трекается.
  - tasks.md - индекс: строка на задачу со статусом и ссылкой на карточку.
  - Перед началом работы проверяй индекс: есть ли карточка. Если нет - создай карточку и строку в индексе.
  - Карточка: проверяемый сценарий (что меняется, в каких файлах), критерий готовности, ссылки и раздел "Прогресс" с текущим состоянием только этой задачи.
  - Статус меняется todo → in-progress → done в индексе и в карточке. Завершённые задачи не удаляются.
  - В начале сессии читай карточку со статусом in-progress, чтобы понять состояние текущей задачи.
  ```

- Если файла `tasks.md` в корне проекта нет - создай его:

  ```
  # Задачи

  tasks.md - индекс. Карточки задач - `tasks/WNN/<слаг>.md`, правила в AGENTS.md.

  ## Задачи

  ```

## Перед началом задачи

1. Проверь, есть ли у задачи критерий готовности. Если критерий сформулировать нечем - это мелкая правка, трекинг не нужен.
2. Открой `tasks.md` и проверь, нет ли уже карточки этой задачи.
3. Если карточки нет - создай `tasks/WNN/<слаг>.md` (WNN - текущая неделя ISO) с разделами: сценарий, критерий готовности, ссылки, прогресс. Добавь строку в индекс со статусом `todo` или сразу `in-progress`.
4. Если карточка есть - переведи статус в `in-progress` в индексе и карточке.

## По ходу работы

Обновляй раздел "Прогресс" карточки: текущее состояние только этой задачи. Статус меняй по мере продвижения: `todo` → `in-progress` → `done`.

## По завершении работы

Сверь результат с критерием готовности, пометь `done` в карточке и индексе. Завершённые задачи и карточки не удаляются.
