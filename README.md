# Agent Starter

Минимальная рабочая папка для начала нового проекта с AI-агентом.

В ней заранее настроены единый файл правил и единая папка скиллов, которые видят Codex, Claude Code и другие совместимые агенты. Правила конкретного проекта записываются в `AGENTS.md`, повторяемые способы работы сохраняются в `.agents/skills/`.

## Структура рабочей папки

```text
my-workspace/
├── AGENTS.md                # или CLAUDE.md
├── sources/                 # входы процесса
├── output/                  # проверяемые результаты
├── evidence-log.md          # история прогонов
└── .agents/skills/          # Codex
    └── <skill>/SKILL.md
```

Тестовый скилл `hello-world` позволяет проверить настройку папки до начала реальной работы.
