# Agent Starter

Папка, с которой удобно начинать работу с агентом. Скачайте её, откройте в Cursor, Claude Code или Codex, и агент сразу видит, где лежат правила и где лежат скиллы.

## Что внутри

**Файл правил `AGENTS.md`.** Здесь живут правила для агента: кто вы, как у вас всё устроено, что агенту можно и чего нельзя. Сейчас файл пустой, и это нормально: правила появляются по ходу работы, первые строки вы напишете вместе с агентом. Рядом лежит `CLAUDE.md`, это тот же файл под другим именем, чтобы Claude Code читал те же правила, что и Codex.

**Папка скиллов `.agents/skills/`.** Скилл это сохранённый способ работы: инструкция, которую агент выполняет по запросу, каждый раз одинаково. Три скилла уже на месте:

- `interview-me` проводит интервью раундами вопросов и собирает контекст о вас, чтобы следующие агенты его не теряли.
- `hq` проверяет и настраивает штаб, то есть эту папку: харнес, главный файл правил, папку скиллов, связь с отделами и `me.md`. Отвечает таблицей ✓/✗ и подсказывает, что починить. Попросите агента: «проверь штаб».
- `pc-avatar` показывает агента в штабе живой 3D-сценой: тело робота это харнес, голова это модель. Робот обходит штаб и отделы, читает их правила и записывает файлы. Скилл кладёт сцену в папку `avatar/` и открывает её в браузере. Попросите агента: «покажи себя».

Свои скиллы добавляйте сюда же, по папке на скилл. Папка `.claude/skills` ссылается на эту же библиотеку, чтобы Claude Code видел те же скиллы.

## Структура рабочей папки

```text
agent-starter/                       # рабочая папка проекта
├── AGENTS.md                        # правила проекта для Codex и других агентов
├── CLAUDE.md -> AGENTS.md           # те же правила для Claude Code
├── .agents/
│   └── skills/                      # общая библиотека способов работы
│       ├── interview-me/
│       │   └── SKILL.md             # интервью для контекста о владельце
│       ├── hq/
│       │   └── SKILL.md             # проверка и настройка штаба
│       └── pc-avatar/
│           ├── SKILL.md             # аватар агента в штабе
│           └── player.html          # плеер 3D-сцены
└── .claude/
    └── skills -> ../.agents/skills  # доступ Claude Code к общей библиотеке
```
